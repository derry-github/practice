一、实践目的：
1、掌握 Spring Boot 框架的开发流程及 MVC 设计模式的应用。                                                       
2、实现学生、课程及成绩的增删改查（CRUD）功能。                                                       
3、理解 Spring Data JPA 的持久化机制及 RESTful API 的设计原则。                                                          
                                                          

二、实践原理：
1、三层架构设计：采用 Controller（展示层）、Service（业务逻辑层）、Repository（数据访问层）的分层思想，实现代码的高内聚低耦合。            

图1 系统架构示意图


2、核心原理：利用 Spring Boot 的自动配置机制简化开发，通过 Thymeleaf 模板引擎渲染前端页面，并结合拦截器（Interceptor）实现权限控制。              

表1 实践步骤安排表
序号    名称    项目    操作步骤/备注等
1    环境搭建    框架初始化    使用 Maven 构建 Spring Boot 项目
2    领域模型    Entity 设计    定义 Student, Course, Grade 等实体类
3    业务逻辑    Service 开发    实现 GradeService 接口及实现类逻辑
4    前后端交互    API 联调    编写 Controller 并整合 Thymeleaf 模板


三、实践设备及用具：
1. 个人计算机（PC）
2. 软件环境：JDK 17, Maven 3.8+
3. 开发工具：IntelliJ IDEA 或 VS Code, 浏览器


四、实践步骤：
1. 创建 Spring Boot 项目，引入 `spring-boot-starter-web`, `spring-boot-starter-data-jpa` 及 `thymeleaf` 依赖。
2. 建立 Entity 层：配置 JPA 实体与数据库表的映射关系。
3. 建立 Repository 层：通过继承 `JpaRepository` 接口实现基础的持久化操作。
4. 开发 Service 层：在 `GradeServiceImpl` 中实现登录逻辑、成绩录入、更新及删除业务，并使用 `@Transactional` 管理事务。
5. 编写 Controller：定义 HTTP 路由，处理页面跳转与数据提交请求。
6. 前端开发：编写 `index.html`, `login.html` 等模板，使用 Thymeleaf 语法绑定后端数据。
7. 权限配置：实现 `AuthInterceptor` 拦截未登录请求。


五、数据记录：
1. 系统初始化：自动创建管理员账号 `admin/admin`。
2. 添加学生：ID=S001, 姓名=张三, 默认密码=123456。
3. 添加课程：Code=CS101, 名称=数据结构。
4. 成绩录入：为张三录入 CS101 成绩为 85.0。
5. 记录更新：将成绩修改为 92.5。


六、实践结果：
系统运行平稳，支持管理员登录后进行全方位的成绩管理。用户界面交互良好，各模块逻辑（如删除课程联动删除成绩）符合预期。


七、实践结论：
Spring Boot 极大地提升了 Java Web 应用的开发效率。通过接口驱动开发和分层架构，使得系统具有良好的可扩展性与可维护性。


八、注意事项：
1.注意在 Service 层合理使用事务注解 `@Transactional` 以保证数据一致性。                              
2.注意 Thymeleaf 模板中的路径引用应使用 `@/` 格式。                              
3.注意敏感操作（如删除）前应进行简单的权限校验。
